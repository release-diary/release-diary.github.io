## 理论基础

圣多纳释放法（Sedona Method）由 Lester Levenson 于 1952 年创立。核心发现是：

**所有负面情绪的根源，只有两种欲望：**

- **想要控制** —— 想让事情按自己的意志运转，却发现控制不了
- **想要认同** —— 想被看见、被接受、被爱，却感到匮乏

当一个情绪涌来，你不需要分析它、解决它，只需要：

1. 允许自己感受它
2. 认出它属于哪一种欲望（控制 or 认同）
3. 问自己：**我能放下这个欲望吗？**

仅仅是「认出」这个动作，就已经是释放的开始。写出来，比想更有效。

## 使用方法

打开 app，在输入框写下此刻脑子里的任何一个想法或感受。

写完后，选择它属于哪一类：

| 标签 | 含义 |
|------|------|
| **想要控制** | 你想控制却控制不了的 |
| **想要认同** | 你想被看见却感到匮乏的 |

按 Enter 释放。然后写下一条。

如果此刻做了什么、或感受到什么转变，切换到**状态**模式记录下来。

---

## 快捷键

| 按键 | 功能 |
|------|------|
| `Enter` | 释放当前记录 |
| `Shift + Enter` | 换行 |
| `⌥ C` | 切换「想要控制」标签 |
| `⌥ A` | 切换「想要认同」标签 |
| `⌥ M` | 切换「释放 / 状态」模式 |

> ⌥ 是 Mac 的 Option 键

---

## 数据安全

数据存在浏览器 localStorage，**清除浏览器缓存会导致数据丢失**。

建议定期备份：右上角 **导出** → 保存 JSON 文件到本地。需要恢复时点 **导入**。

不同设备的数据相互独立，可通过导出 / 导入在设备间迁移。
