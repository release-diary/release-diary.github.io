# 释放日记

把恐惧从脑子里拿出来，然后带着更轻一点的身体继续走。

---

## 下载和使用

1. 点击页面右上角绿色的 **Code** 按钮 → **Download ZIP**
2. 解压，找到 `app.html`
3. 双击用浏览器打开，就可以用了

不需要安装任何东西，不需要联网。

---

## 是什么

一个本地运行的私人日记工具，专门用来「释放」脑子里的负面情绪。

每条记录需要标注这个情绪属于哪种类型：

- **想要控制** — 你想控制却控制不了的事情
- **想要认同** — 你需要被看见、被理解的感受

写完一条，脑子轻一点，然后继续。

---

## 功能

- **两种记录模式**
  - 「释放」模式：写情绪，必须选标签才能提交
  - 「状态」模式：记录当下发生了什么、做到了什么
- 每条记录自动打上时间戳（精确到分钟）
- 同一时段的记录自动归组
- 数据存在浏览器本地，关掉再开还在
- 支持导出备份 / 从备份恢复，防止数据丢失

---

## 快捷键

| 按键 | 功能 |
|------|------|
| `Enter` | 提交当前记录 |
| `Shift + Enter` | 换行 |
| `⌥ C` | 切换「想要控制」标签 |
| `⌥ A` | 切换「想要认同」标签 |
| `⌥ M` | 切换释放 / 状态模式 |

> Mac 上 ⌥ 是 Option 键。

---

## 数据备份

数据存在浏览器的 localStorage 里。**清除浏览器缓存会丢数据**，建议定期备份：

- 右上角点 **导出** → 下载 JSON 文件保存到本地
- 需要恢复时点 **导入** → 选择之前导出的 JSON 文件
